# Contributing to Ezreal Media Archive

Thank you for helping improve the Ezreal Media Archive.

## Ways to contribute

- Report bugs
- Request archive content updates

## Issue guidelines

Please use the provided issue templates.

A good issue includes:

- clear title
- what you expected
- what happened
- reproducible steps (for bugs)
- screenshots or links (if relevant)

## Content and media requests

If you want to add or correct archive entries, open a Content Request issue and include:

- skin name
- media category
- game (if applicable)
- expected release year
- source/reference links
- notes on why the item should be included

## Community standards

By participating, you agree to communicate respectfully and constructively.
Harassment, hate speech, or abusive behavior is not tolerated.
