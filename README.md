# Ezreal Media Archive

![Ezreal Media Archive](https://assets.timfernix.dev/archive.png?v=2)

A curated archive of official Ezreal media from League of Legends and related games.

This repository currently contains the frontend for browsing media entries.
Here is the repository for the backend worker: [Ezreal Archive Backend](https://github.com/timfernix/ezreal-archive-backend)

## What this project is

Ezreal Media Archive is a searchable gallery that helps fans browse official Ezreal assets.
