# Changelog

Notable updates to the Ezreal Media Archive.

## 2026-11

- Main: Almost every item now has a generated thumbnail to reduce loadingtime & responsiveness
- Fixed loading animation and added skeleton placeholders
- Added "Newest First" (by upload order) as the default sorting and "Newest Skin" for the previous skin-release-date order.
- Added a "New" badge for assets uploaded in the last 7 days and an "Uploaded" date in the lightbox technical info.
- Faster loading: gallery cards now use small thumbnails and short video previews, with loading placeholders and prioritized filter icons.
- Lightbox: neighbouring images are preloaded and swiping left/right works on touch devices.
- The archive remembers your scroll position when returning from an asset, the timeline, or a reload.
- Shared asset links now show the asset's title and image in link previews (e.g. Discord).
- Fixed jumping while scrolling

## 2026-10

- Improved the media lightbox with keyboard navigation, image zoom, and panning.
- Added full skin release dates for more accurate chronological sorting.
- Added active-filter indicators to filter menus.
- Added info modal
- Added Timeline page

## 2026-09

- Added Giphy and Klipy support, audio playback, and more detailed media information.
- Expanded media categories and improved filter controls and mobile layouts.
- Added a versioned static catalog, search, sorting, and paginated media browsing.

## 2026-08

- Improved search, sorting, and pagination, including automatic loading of more results.
- Added icons to skinline, game, and category filters.

## 2026-07

- Introduced paginated browsing (v1.2), with eager loading for smoother media previews.
- Improved mobile navigation and loading more results after searches and filter changes.

## 2026-06

- Launched the archive with a searchable, filterable media gallery and lightbox.
- Added image and video previews, external links, asset details, and shareable URLs with filters.
- Introduced newest-first sorting, release-year metadata, and project contribution guidelines.
